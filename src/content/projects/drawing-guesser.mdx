Trained on the QuickDraw dataset with CreateML and run entirely on-device
through CoreML and Vision — no network round trip, so predictions update as the
stroke is still being drawn.

Most of the actual work was model fine-tuning rather than app code. Getting a
classifier that behaves acceptably on partial, mid-stroke input is a different
problem from getting one that scores well on complete drawings, and the gap
between those two is where the interesting debugging lived.

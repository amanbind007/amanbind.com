## Why breadth

When I moved from mobile into infrastructure, I did not want to be the engineer
who knows one cloud primitive deeply and everything else by rumour. Certification
is an imperfect proxy for competence, but the study path forces you across the
whole surface: networking, identity, cost, resilience, data, security posture.

I worked through the architecture track first, then DevOps and operations, then
security. Each one changed how I designed the platform work I was doing at the
same time — the Security Specialty material in particular reshaped how I thought
about the deployment permission model.
